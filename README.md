# 小约翰可汗语录 · 通辽宇宙档案馆

> TONGLIAO ARCHIVE
> 一座纯静态的「小约翰可汗」语录档案馆：收录 **44 期视频 · 552 条语录**，涵盖「奇葩小国」「硬核狠人」「神奇组织」「小约翰」四大系列。支持全文检索、经典语录标记、语录直达 B站名场面、单条语录分享链接与夜读模式。

**线上地址**：https://yulu.csilent.top
**源代码**：https://github.com/csilenti/tongliao-archive

---

## 项目特色

- **档案馆三级结构**：首页为「视频档案大厅」（一份档案 = 一期视频），点进档案卡调阅该期的完整语录，系列 → 档案 → 语录层层递进
- **语义化的数据源**：所有内容来自唯一的 Markdown 源文件。`**粗体**` 语录自动识别为「经典语录 / 名场面」；语录中「奇葩小国42」等跨期引用自动转为站内链接，形成通辽宇宙引用网
- **零手工统计**：语录数、期数、经典数、BV 号等全部由脚本从源文件动态解析，数据与展示永不脱节
- **检索室**：按关键词搜索档案（命中标题 / 简介 / 语录内容 / BV 号），按系列筛选
- **语录直达名场面**：语录带时间标记（如 `（5min）`、`（13:44处）`）时自动渲染跳转按钮，点击直达 B站视频对应时刻
- **单条语录分享**：每条语录可复制独立锚点链接（`#/archive/xxx?q=N`），打开后自动定位并高亮闪烁
- **随机调阅**：首页与导航栏均有一枚骰子按钮，随机抽一份档案翻着看
- **夜读模式**：完整的深色主题（夜读档案馆配色），跟随系统偏好、手动可切、localStorage 记忆、防首屏闪烁
- **纸感档案馆视觉**：浅色纸张底色 + 砖红 / 芥末黄 / 橄榄绿，全文「抖音美好体」，克制的滚动入场 / 调阅转场 / 纸胶带装饰，支持 `prefers-reduced-motion` 降级
- **性能**：封面图构建期压缩为 WebP 双档（缩略图 + 大图），全站图片体积约为原始 PNG 的 1/5；数据文件经过瘦身，语录对象不重复存储档案字段
- **纯静态、零依赖**：无框架、无运行时依赖，任意静态托管即可部署

## 目录结构

```
├── index.html            # 全部页面（首页 + hash 路由详情页，单文件应用）
├── favicon.svg
├── data.js               # 由源文件解析生成的结构化数据（浏览器无 CORS 直接读取）
├── build-data.js         # 数据解析脚本：Markdown → data.js
├── build-webp.py         # 封面压缩脚本：photo/*.png → photo_webp/*.webp（大图 + 缩略图）
├── 小约翰可汗语录.md       # ★ 唯一内容源：所有语录、BV 号均在此维护
├── photo/                # 封面原图（PNG，源文件，站点不直接引用）
├── photo_webp/           # 构建生成的 WebP 封面（thumb/ 为 480w 缩略图，其余为 960w 大图）
└── fonts/                # 抖音美好体（思源黑体切片，可自由使用）
```

## 本地预览

双击 `index.html` 即可（数据经 `data.js` 注入，`file://` 协议下无 CORS 问题），无需启动任何服务。

## 更新语录内容

1. 编辑 `小约翰可汗语录.md`，按现有格式追加内容：
   - `## 系列` / `### 标题 -- 主题` 组织层级
   - 语录中的 BV 号自动识别为视频出处
   - `**加粗**` 的语录自动标记为「经典语录」
   - 语录中的「奇葩小国42」等期数引用自动生成站内跳转
   - 语录标注时间（`（5min）` 或 `（13:44处）`）会自动生成 B站时间戳跳转按钮
2. 有新封面图时，压缩封面：

```bash
python build-webp.py
```

3. 重新生成数据：

```bash
node build-data.js
```

4. 刷新页面即可，统计数据自动更新。

## 部署

纯静态站点，把以下内容上传至任意静态托管（本项目使用腾讯云 EdgeOne Pages）：

```
index.html  favicon.svg  data.js  fonts/  photo_webp/
```

> `photo/`（PNG 原图）无需上传；`photo_webp/` 缺失时页面会自动回退到 PNG 原图路径，但体积大很多，不建议省略。

## 技术说明

- 原生 HTML / CSS / JavaScript，单文件应用，hash 路由实现档案详情页
- 深浅主题基于 CSS 自定义属性整体切换，约 25 个语义变量控制全站配色
- 数据流：`Markdown → build-data.js → data.js → 前端渲染`，语录与档案字段分离存储（语录仅存 `episodeId` 引用，档案级信息由前端推导）
- 构建（可选）：Python 3 + Pillow（仅 `build-webp.py` 需要）
