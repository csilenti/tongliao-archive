# 小约翰可汗语录档案馆

> 通辽宇宙语录 · TONGLIAO ARCHIVE
> 一个纯静态的「小约翰可汗」语录收藏档案馆：收录 **44 期视频 · 552 条语录**，涵盖「奇葩小国」「小约翰」「硬核狠人」「神奇组织」四大系列，支持在线检索、经典语录标记与视频出处直达 B 站。

**线上地址**：https://yulu.csilent.top

---

## 项目特色

- **档案馆三级结构**：首页为「视频档案大厅」（一份档案 = 一期视频），点进档案卡查看该期的完整语录详情，系列 → 档案 → 语录层层递进
- **语义化的数据源**：所有内容来自唯一的 Markdown 源文件，`**粗体**` 语录自动识别为「经典语录 / 名场面」，语录中「奇葩小国 42」等跨期引用自动转为可点击的内链，形成通辽宇宙引用网
- **零手工统计**：语录数、期数、经典数、BV 号等全部由脚本从源文件动态解析，数据与展示永不脱节
- **检索室**：按关键词搜索档案（命中标题 / 简介 / 语录内容 / BV 号）、按系列筛选、多种排序
- **纸感档案馆视觉**：浅色纸张底色 + 砖红 / 芥末黄 / 橄榄绿，全文「抖音美好体」，克制的滚动入场与调阅转场动画，支持 `prefers-reduced-motion` 降级
- **纯静态、零依赖**：无框架、无构建依赖，任意静态服务器即可运行

## 目录结构

```
├── index.html            # 全部页面（首页 + hash 路由详情页，单文件应用）
├── favicon.svg
├── data.json / data.js   # 由源文件解析生成的结构化数据（data.js 供浏览器无 CORS 读取）
├── build-data.js         # 数据解析脚本：Markdown → data.json / data.js
├── server.js             # 本地预览服务器（Node，端口 3001）
├── 小约翰可汗语录.md       # ★ 唯一内容源：所有语录、BV 号均在此维护
├── fonts/                # 抖音美好体（思源黑体切片，可自由使用）
└── photo/                # 各期视频封面（来源：B 站视频封面，版权归原作者）
```

## 本地运行

```bash
# 1. 启动本地服务器
node server.js
# 2. 打开 http://localhost:3001
```

## 更新语录内容

1. 编辑 `小约翰可汗语录.md`，按现有格式追加内容：
   - `## 系列` / `### 第 X 期 标题` 组织层级
   - 语录中的 BV 号会自动识别为视频出处
   - `**加粗**` 的语录会标记为「经典语录」
   - 语录中出现「奇葩小国 42」等期数引用会自动生成站内跳转
2. 重新生成数据：

```bash
node build-data.js
```

3. 刷新页面即可，统计数据自动更新。
